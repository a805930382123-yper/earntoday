# 今天又赚了多少

一款 Windows 桌面陪伴小组件：蓝发女孩或狸花猫「咪宝」趴在工资卡片上，陪你上班并实时显示今天已经赚到的钱。

## 下载与安装（Windows 64 位）

**[下载最新版 Windows 安装包](https://github.com/a805930382123-yper/earntoday/releases/latest)**

当前正式版：[v0.3.1](https://github.com/a805930382123-yper/earntoday/releases/tag/v0.3.1)。新增全局快捷键隐藏/恢复，保留设置草稿，并优化隐藏时的动画与设置页布局。

在发布页面下载 `EarnToday_版本号_x64-setup.exe`，双击并按提示安装，然后从开始菜单打开「今天又赚了多少」。无需安装 Node.js、Rust 或开发工具，也不需要保留项目文件夹。

安装器会检查 Microsoft Edge WebView2；如果电脑尚未安装该运行环境，需要联网下载。已有 WebView2 的电脑可直接安装，程序启动后无需开发服务器。

v0.2.0 用户首次升级：先从托盘退出旧版，将 `%APPDATA%\earn-today` 复制到本机备份目录，再以同一 Windows 用户用最新版安装包覆盖原安装，沿用原目录，无需先卸载。v0.3.0 用户可在应用设置中检查更新。真实覆盖安装与应用内升级的数据保留记录见 [自动更新交付记录](docs/updater.md)。

GitHub 的「Code → Download ZIP」下载的是源码，适合开发使用。源码中的 `EarnToday.exe` 是本地开发启动器，必须先完成下文的构建步骤才能使用。

## 功能

- 无边框、透明、置顶、可拖动的桌面悬浮窗
- 根据月薪、每月工作天数、上下班与午休时间实时计算今日收入（每秒刷新，基于系统时间重新计算，睡眠/隐藏/重启后依然准确）
- 工作状态判断：上班前 / 努力赚钱中 / 午休充电中 / 今日打工完成 / 今天休息啦
- 自定义工作日：周一至周日任意勾选，支持双休/单休快捷选择，至少选一天；每周选择只判断哪天上班，每月工作天数仍手动填写并用于日薪。休息日收入为零、桌宠睡觉，不显示下班倒计时或触发庆祝，隐私和迷你模式继续生效
- 工作进度条、已工作时长、距离下班倒计时
- 午休自动切换为独立闭眼趴睡素材；收入、有效工时、进度暂停，距离下班继续倒计时
- 蓝发女孩伴随轻柔呼吸动画；两种姿态柔和淡入淡出，睡眠 Zzz 缓慢明暗变化，尊重系统减少动态效果设置
- 系统托盘：显示 / 恢复窗口、设置、退出程序；恢复保留当前页面、窗口尺寸、位置和未保存的设置
- 一键隐藏与恢复（v0.3.1 起）：`Ctrl+Shift+H`；设置页底部可关闭或重试注册快捷键。冲突时保留托盘恢复；隐藏后暂停可见动画，恢复按当前时间重算，不补播积累或下班动画。实现及验收见 [隐藏与恢复](docs/visibility.md)
- 设置窗口：参数校验、日薪时薪实时预览，首次使用自动引导
- 皮肤主题：默认「蓝色大肥鱼」与奶油焦糖绿色的「咪宝」，上班/午休/下班/设置四角色预览，主题与工资独立保存，重启恢复上次选择
- 迷你模式：260×108 横向桌宠，保留角色、收入和状态；展开按钮恢复完整卡片，设置返回及重启保持模式
- 隐私隐藏：眼睛按钮一键遮盖收入，两种窗口模式与两套主题均支持；后台继续计薪，恢复显示最新金额，重启保持隐藏
- 隐私疑惑表现：工作中隐藏收入后，蓝色大肥鱼显示疑惑表情与蓝色问号，咪宝显示疑惑表情与暖橙色问号；午休和下班保留原角色、不显示问号，收入仍然隐藏。点击互动结束后恢复当前状态
- 桌宠轻互动：点击角色，按工作/午休/下班状态显示短暂反应与气泡；约 1～1.2 秒恢复、1.5 秒冷却。完整/迷你/隐私模式均支持，拖动角色仍可移动窗口，状态切换立即结束互动
- 本地 JSON 持久化：工资设置 + 悬浮窗位置（逻辑坐标，多显示器/HiDPI 下可恢复）
- 应用内更新：启动后非阻塞检查一次，也可在设置页手动检查；用户确认后显示下载进度、验证签名并安装重启。安装前持久化设置并核对本机备份。
- 本机配置备份与恢复：保持原设置目录和字段，旧配置补充新字段默认值，损坏配置暂停写入；恢复需要选择有效备份并再次确认。
- V1.4 趣味积累：设置 → 显示方式 → 趣味积累 → 保存。蓝色大肥鱼的白米饭碗、咪宝的小鱼干罐按当天有效工作时间分成十段逐渐装满；午休保持、下班装满、上班前和休息日为空。老用户继续默认实时金额。
- 主题化进度与文案：完整模式显示十个小饭碗或小鱼干及阶段数；迷你模式显示容器、主题图标和 `n/10`。各阶段、午休和休息日使用角色专属文案，正常跨过一个节点时出现一次投放和短提示。隐藏隐私时沿用原遮盖界面，容器、十格和阶段数全部消失。

## 仓库中的桌宠自主小动作

当前源码已接入确认后的局部动画：蓝色大肥鱼慢眨眼、小哈欠，以及咪宝双耳轻动、尾尖轻摆。眨眼/动耳随机等待 30～45 秒，哈欠/摆尾随机等待 1～3 分钟；尾尖仅完整模式播放。设置中的“桌宠自主小动作”可关闭，系统减少动态效果优先。点击、拖动、隐藏窗口和特殊表情会暂停或打断动作。

素材、七个实际尺寸样本和验证结果见 [自主小动作接入记录](docs/autonomous-integration/README.md)。开发预览运行 `npm run dev` 后打开 `/action-preview.html`。此处记录仓库源码进度，现有 v0.3.1 Release 安装包和应用内更新源保持原发布内容；体验新代码请运行 `npm run build:exe`。

## 源码构建与本地双击启动

日常使用项目根目录下的 `EarnToday.exe`：

1. 双击 `EarnToday.exe` 即可启动；若程序已在托盘运行，会显示并切换到窗口。
2. 该启动器会调用 `src-tauri/target/release/earn-today.exe`，请保留此文件和目录结构。正式版已内置页面与图片，不需要启动开发服务器。
3. 首次构建或修改代码后，执行以下命令，自动构建正式版应用和启动器：

```powershell
npm run build:exe
```

仅重新编译启动器（不更新主程序）时，可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File tools\build-launcher.ps1 -LauncherOnly`。

不要将未启用 `custom-protocol` 的 Cargo 构建产物用于日常启动；这类 EXE 仍会连接 `devUrl`，开发服务器关闭后会出现“无法访问此页面”。本项目默认启用此功能；`npm run build:exe` / `npm run tauri build` 还会先更新前端资源，避免打包旧页面。

## 构建 Windows 安装包

```bash
npm run tauri build
```

产物位于 `src-tauri/target/release/bundle/nsis/`。

仓库的 `.github/workflows/release.yml` 由 Actions 页面手动运行，构建、签名并执行真实旧版覆盖验收，默认只生成候选 artifact。发布新版本前，同步修改 `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json` 的版本号和锁文件，补充版本说明；应用内更新验收通过后，用 `promote-candidate.yml` 将同一组候选文件发布到 Releases。推送源码或标签不会自动分发新版。完整步骤见 [自动更新交付记录](docs/updater.md)。

环境要求：Node.js ≥ 22.6、Rust（MSVC）、Visual Studio Build Tools（C++ 工作负载）、WebView2。
