## 局部返修与播放顺序

旧四张整图的局部线稿、毛发、玩具和透视也与正式底稿不同，不能可靠直接贴回。因此没有继续使用旧整图轮播。原用户素材保留在 `docs/action-preview/sources/`。

少女眼口使用内置 `image_gen` 对正式底稿的脸部裁片补画，然后只通过固定眼口遮罩取用局部。生成候选整张裁片不会直接显示。原图的发型轮廓、发饰、袖口、双手、小伙伴及非动作区保持；睫毛与蓝发交界的原睫毛抗锯齿像素纳入眼部处理，避免旧睫毛残影。

咪宝使用正式原图的局部毛发像素重采样，完全不替换猫脸、眼睛、胡须、鱼玩具或爪子。动作连接处位移平滑归零。没有把独立尾巴叠在原尾巴上，也没有先挖掉原尾巴造成缺口。

每组首尾均直接引用正式原始 PNG URL，不另画恢复状态。播放前后各留 360 ms 原图观察时间。回程复用已有图，共 **9 张独立返修帧**，没有为凑数复制十二张。少女帧为 1235 × 561，咪宝帧为 1859 × 846；保持各自正式原图画布、比例、object-fit、遮罩和偏移。没有逐帧裁边、缩放、居中或整角色运动。

双耳更新：旧单耳方案在耳根上方就逐渐归零，导致耳尖弯、耳根不动。新版把完整耳廓与耳根作为一起轻转的局部，左右峰值约为向外 4.8°/4.0°，耳根另有少量平移；仅耳根下方连接毛发衰减至固定头部。独立检查分别验证两侧耳根确实变化，并保护双眼/眉、下部猫脸、胡须、爪子、鱼玩具和尾巴。三个独立姿态加回程复用，减少原有三段播放的跳动。仍以实际尺寸视觉确认自然程度，不把像素检查当作自然度评分。

耳根幅度微调：保留双耳上部的轻动，耳根旋转权重降至原来的 60%，附加平移约减半；耳根下方过渡范围从左 40/右 55 源像素收窄到 22/28 源像素，避免把头部轮廓一起拉动。起动、回程与实际容器尺寸不变。

半闭眼是真实补画的眼睑/虹膜遮挡状态，不是整图缩放或透明度变化。在固定原虹膜范围内，蓝色像素计数从 8269 降至 3130（约 37.85%），闭眼为 24 个抗锯齿相关像素；这只是辅助检查，不能替代视觉判断。原图与所有少女返修帧的 alpha 完全相同。

## 无损源、运行资源与差异证据

- `generated/`：保留四张补画候选的无损 PNG；输入裁片在 `edit-inputs/`。生成模式与最终提示词集见 [generation-prompts.json](generation-prompts.json)。
- `lossless/`：九张无损局部合成源，以及四组完整原生尺寸允许区遮罩。
- `src/dev/repaired/`：按项目现有 PNG 资源规范导出的相同无损帧、开发遮罩和播放 manifest；导出像素与 lossless 逐像素相等。
- [pixel-checks.json](pixel-checks.json)：各帧变化范围、变化像素数、区域外差异与 alpha 差异。
- [independent-checks.json](independent-checks.json)：独立复核原图哈希、运行导出、手爪接触点、保护区、alpha 小孔以及七个样本的动作可见范围。

## 七个样本的实际播放

浏览器 100% 缩放下，少女眨眼完整/迷你、少女哈欠完整/迷你、咪宝动耳完整/迷你，以及咪宝摆尾完整，均通过以下检查：

1. 正式原图进入、按指定状态顺序播放、回到同一正式原图 URL。
2. 原图与返修帧的容器位置、尺寸、object-fit、object-position、mask 一致；图片本身无 CSS 动画、变形或淡化。
3. 手动逐帧会取消剩余播放；无自动重播、随机调度、业务写入或 localStorage 改动。
4. 透明棋盘、浅色、深色、锚点与允许区检查；展开的差异图可实际加载。
5. 窄屏换行保留样本实际尺寸，不把角色缩小或放大。
