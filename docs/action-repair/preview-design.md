# 预览验收展示方案

应用 frontend-design 技能，保留已有七个样本和操作位置，不重做产品界面。

- 颜色：页面底 `#f2f4f6`、纸面 `#ffffff`、正文 `#26323c`、操作 `#325e78`、允许区 `#b4288c`、实际差异 `#14becd`。状态只用于显示候选/待补，不把像素通过当成视觉通过。
- 字体：沿用项目现有中文系统字体；标题 26 px、动作标题 16 px、控件 12 px、证据说明 12 px。所有内容左对齐，实际样本保持原尺寸。
- 布局：保留四组、两列的现有样本布局；每组下方用可展开的证据区放底稿路径、允许区和差异图。窄屏改为单列，不缩放样本。

```text
标题 + 原图进入/返回说明
背景切换 | 接触点 | 允许区域
动作名称 + 像素检查结果 + 视觉待确认
完整 260×276 | 迷你 260×108
播放一次 / 逐帧 / 原图叠加
实际修改范围 + 序列
展开：原图、允许区、各帧像素差异
```

自查调整：去掉原先无序动作上的 01—04 装饰编号和全大写眉题；主视觉仍是实际角色。增加的色彩仅用于解释差异，不新增装饰动画或遮盖问题的效果。沿用卡片容器是用户明确要求，不借优化预览改变正式角色布局。
