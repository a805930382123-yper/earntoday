# v0.2.0

本次包含自定义工作日及工作中隐私隐藏的视觉优化，保留现有工资计算、主题、迷你模式与桌宠互动。

- 设置支持周一至周日任意勾选，以及双休、单休快捷选择，至少选择一天。旧配置默认周一至周五。
- 每周工作日只决定当天是否上班；每月工作天数继续手动填写，日薪和时薪公式保持不变。
- 休息日显示零收入及原睡觉角色，不显示工作进度、下班倒计时或庆祝；迷你模式和隐私隐藏继续生效。
- 蓝色大肥鱼和咪宝工作中隐藏收入时显示各自的疑惑角色及主题问号。午休、下班恢复原角色且不显示问号，金额继续隐藏。
- 保留本地配置、设置校验和点击互动，互动结束后恢复正确的状态与隐私展示。

验证：37 项工资测试、12 项 Rust 测试通过；两主题、两模式、四档 DPI 的浏览器检查及 Windows 实际保存、重启和隐私检查通过。详细验收见 `docs/ui/work-weekdays-v1.3.md` 和 `docs/ui/privacy-working-design.md`。

Windows 64 位安装包由仓库发布流程构建并检查安装后的内置页面与图片。已有用户直接安装更新；无需开发服务器。若未安装 WebView2，首次安装需联网下载运行环境。

沿用现有限制：不支持跨午夜班次、节假日和调休，不自动统计每月工作天数。
