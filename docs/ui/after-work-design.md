# 下班模块设计

沿用已有 `workState` 的 `after`，计算函数已有封顶，不新增累加器。周末规则保持原样。

色板：冰白 #f5fbff、柔蓝边框 #b9d9ff、完成蓝 #5278cf、金额深蓝 #263b80、柔金 #e6bc66、心形粉 #efa6b7。
数字沿用 Segoe UI Variable Display，提示条使用微软雅黑圆润字重。原人物、卡片、数字位置不变，260×240 在底部增加36px透明空间至260×276，各状态使用同一窗口尺寸。设置仍400×600。

```
          开心女孩 + 小白猫
    今天已经赚到       原设置/隐藏按钮
               最终金额
             ✓ 今日打工完成
    [==============] 100%
       已工作实际时长 | 已下班
       猫  下班！又是美好的一天  心
```

审查：参考大图不能直接缩成背景；采用真实React金额、进度与提示条。新标签使用原状态行，避免小窗口金额右侧过度拥挤。只加一颗小心，不加反复流光或散落星星。独立透明角色素材替换开心分支，不触碰午休素材。提示条360ms入场，每个本地日期在应用会话中仅一次，返回设置不会反复播放，兼容减少动态效果。
