# 咪宝主题设计与素材记录

## 施工前设计

对象是办公悬浮工资组件。记忆点放在真实狸花猫的白爪、黄绿色眼睛和环纹尾巴，卡片安静衬托角色。

配色：奶油白 #FFF9EE、浅焦糖 #E7BA83、深棕 #56351F、暖黄 #FFD786、嫩绿 #9CC45B、浅绿 #EAF2D0。金额采用深棕，绿色用于工作进度与保存操作；猫爪采用低对比焦糖色。

字体：沿用现有 Windows 中文字体及数字字体，保留金额与时间的字号、字重和等宽数字，避免切换主题导致信息跳动。

布局：角色居中贴合卡片上沿；卡片、金额、时间和按钮共享原布局。设置页保留 190×140 的角色容器及双列表单；主题列表两列并排，上方封面，下方名称、简介和当前使用标记，预览三状态居中对齐。

对照提示词复核：暖奶油与圆角由参考稿明确指定；不增加泛用营销装饰、额外业务卡片或字体依赖。只保留一枚独立淡猫爪，鱼玩具和枕头随角色素材展示，优先确保狭小窗口内金额与按键清楚。

## 素材来源

参考资料实际位于 docs/mibao/（原猫照片为 cat-reference.jpg），共照片与四张状态参考稿。使用内置 imagegen，先由原照片与上班稿生成 working；其余三态同时参考该角色、原照片及对应状态稿。输出独立高清透明 PNG，不包含卡片、表单、文字或金额。原始生成文件保留，生产副本位于 src/assets/mibao/。

四张静态角色图沿用小幅呼吸与 Zzz；没有尾巴/眼睛分层，首版不强行扭曲整张图模拟摆尾或眨眼。

## 截图复核与调整

在真实 React 渲染截图中确认四张角色图的耳朵、尾巴、爪子和计算器完整，前爪与卡片有接触，金额无遮挡。首次两列主题卡片让内容高度达到 589px，超出 400×600 窗口的内边距；缩短介绍、预览分隔和卡片内边距，保留全部简介和四状态预览，最终无需扩大窗口。沙漏原本保留一条蓝色描边，改为主题图标变量；默认蓝主题仍使用原值。
