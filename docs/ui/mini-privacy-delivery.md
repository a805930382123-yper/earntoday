# V1.1 迷你模式与隐私隐藏交付

## 操作

完整卡片左上缩小按钮进入迷你模式；眼睛按钮隐藏收入。迷你卡片右上依次为恢复完整模式、隐藏/显示收入、设置、隐藏到托盘。所有入口始终可见，不依赖悬停。隐藏收入与隐藏到托盘是两项独立操作。

## 文件和实现

- `src/display/DisplayProvider.tsx`：共享 windowMode/ privacyMode，配置加载与 display-updated 同步，两个命令分别保存；设置/主题页面切换不卸载 Provider。
- `src/components/DisplayControls.tsx`：缩小/展开、眼睛按钮，迷你页设置和托盘入口；标签不带工资数值。
- `src/components/MiniWidget.tsx`、`src/display.css`：260×108 横向布局，左侧约 35% 角色、右侧「今天已赚」、金额和状态；不包含进度、工时、倒计时或下班横幅。
- `src/components/Widget.tsx`：原有业务计算和每秒刷新继续共用，只在 JSX 分支选择完整/迷你布局，隐私时直接删除真实金额节点；完整卡片原 x10/y97/240×140 几何和信息位置保留。
- `src/themes/catalog.ts`、`src/themes/mibao.ts`：增加可选 mini 宽度、垂直位置和三状态水平偏移，仍使用原主题注册表和素材。
- `src/App.tsx`、`src/main.tsx`：接入显示状态 Provider 与局部样式。
- `src-tauri/src/config.rs`：保存 windowMode、privacyMode、完整窗口锚点和位置对应缩放因子；旧配置默认 full/visible。错误配置报告 configError，损坏或读取失败时不静默恢复可见金额。
- `src-tauri/src/display_window.rs`：逻辑窗口尺寸、物理工作区夹紧、旧配置位置兼容、跨 DPI 保存坐标恢复。
- `src-tauri/src/lib.rs`：两个独立模式命令、显示状态事件、设置和托盘返回恢复模式；复用一个原生窗口；原生 Moved 事件保存实际拖动位置，忽略设置页及过期移动事件。
- `tools/verify-display.cjs`、`tools/verify-display-desktop.cjs`：浏览器与正式 Windows EXE 验收；原主题/小组件测试增加新监听和桥接支持。
- `README.md`、本文件、`mini-privacy-design.md`：操作与设计/交付记录。

工资公式、状态判定和午休算法未改，src/salary/calc.ts 的 SHA256 与原主题系统基线相同。没有新增依赖，没有复制主题或业务计算体系。

## 角色复用

两套主题均直接复用既有 working/lunch/finished 高清透明 PNG，没有重绘或修改原美术文件。女孩通过 154px 宽图、-42px 水平与 16px 顶部偏移，展示完整头饰、五官和双手；咪宝为 164px 宽图，三态偏移 -16/-8/-16px，展示耳朵、脸和白爪。只裁去侧边长发、尾巴或身体，不要求迷你展示完整全身。

午休沿用睡眠图与 Zzz，下班显示开心图和「已下班」；上班前/周末沿用原判定与文案。保持轻微呼吸并支持减少动态效果。蓝主题和咪宝的原完整及设置视觉继续保留。

## 原生窗口与位置

完整为 260×276，迷你为 260×108，设置为 400×600，均是逻辑像素，由原生 set_size 真实调整，窗口不销毁重建。进入迷你保存完整位置；移动迷你时只更新当前位置，恢复完整时回到进入迷你前的锚点。设置页居中时不覆盖小组件锚点，关闭设置或保存工资回到当前模式。

使用保存的缩放因子还原物理位置，再按显示器工作区夹紧，包括负坐标显示器和任务栏可用区域；移除显示器或位置越界时选就近屏幕。置顶、透明、拖动区域和托盘事件沿用现有实现，按钮高于拖动层。

## 隐私与配置

开启隐藏后显示「¥ ••••••」和「收入已隐藏」，不将真实数字留在主窗口 DOM、tooltip、标题或工资无障碍标签中，也不对原数字做淡出动画。进度、工时、倒计时及状态保留；后台继续按系统时间计算，恢复显示时使用当前值。

启动先显示遮盖占位，读取显示配置后才允许真实数字显示。已有 hidden 从第一帧就生效；读取/格式错误时保持遮盖并明确提示，可重新读取或主动打开设置检查并保存。设置页允许主动查看编辑工资，但返回不重置隐私状态。

隐藏按钮先立即遮盖，再持久化；若保存失败仍遮盖并提示「重启后可能恢复显示」。恢复金额必须等保存成功才展示，失败不会解锁。主题、工资、位置、两个模式分别更新，互不覆盖；两个模式与工资的 Rust 保存失败不会先提交新的内存配置。
