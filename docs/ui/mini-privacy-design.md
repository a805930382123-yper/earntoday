# V1.1 迷你模式与隐私设计

首轮施工前检查：单一 Tauri WebView 在 260×276 完整窗与 400×600 设置页之间切换；工资数据由 Widget 每秒基于时间计算，主题由同一 Provider 管理。当时未提供迷你参考图，按任务规范设计。2026-10-13 已收到参考图，后续视觉适配见 [参考图适配记录](mini-reference-refinement.md)。

配色：沿用蓝主题蓝 #4A9DFF、浅蓝 #E8F3FF、墨色 #20354A；咪宝奶油 #FFF9EE、焦糖 #E7BA83、深棕 #56351F 与绿色 #9CC45B。无第三套视觉体系。

字体：沿用 Windows 中文字体、等宽数字。迷你金额 24px，标题 10px，状态 10px；完整金额字号保持原值。隐私遮盖保持行高且不渲染真实数字。

布局：260×108，左侧约 35% 角色，右侧标题/金额/状态。右上恢复、眼睛、设置、托盘按钮始终可见，拖动层位于按钮下方。完整窗左上增加缩小和眼睛，原设置/托盘入口保留。

```
┌ 角色头部与前爪  [展开][眼睛][设置][托盘] ┐
│                今天已赚                │
│                ¥168.35 / ¥••••••       │
```

复核：独立紧凑信息布局，不机械缩放完整工资卡。复用现有三状态透明 PNG，只在主题配置中给出裁切定位；不新增角色美术、不重复计算、不增加营销装饰。关闭金额动画和淡出，隐私切换立即移除数字，启动/读取失败时先遮盖并明确说明失败。

原生行为：复用主窗口，采用逻辑尺寸，按显示器物理工作区夹紧位置，进入迷你前保存完整模式锚点；设置返回与托盘恢复读取保存模式。窗口模式与隐私状态分别保存，与工资和主题互不覆盖。

截图复核：首次女孩 164px 裁切使头饰右沿过近；改为 154px、向左偏移 42px、顶部偏移 16px，完整保留五官与头饰。咪宝按三个姿态单独设置水平偏移，保留猫耳和白爪；允许裁去长发、身体两侧与尾巴，符合头部迷你展示目标。添加极轻接触阴影，其他装饰省略。

位置保存补充当前显示器缩放因子，避免混合 DPI 下将逻辑桌面坐标直接与物理显示器边界比较；旧配置缺少因子时按显示器范围推断。金额遮盖仅替换 JSX 数字节点，没有数字淡出动画、残留 title 或金额无障碍标签。
