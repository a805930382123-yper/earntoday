# 迷你模式参考图适配

参考：`docs/mini-mode/mini-mode-concept.png`。本轮只增量调整展示，继续复用现有主题、角色、工作状态、隐私与原生窗口逻辑。

施工前视觉方案：

- 蓝色主题：雪白 #F7FBFF、冰蓝 #E8F3FF、描边 #A9CFFF、深蓝 #163D82。
- 咪宝主题：奶油 #FFF9EE、米色 #F7E9D4、暖描边 #ECD1AB、焦糖 #56351F、嫩绿 #9CC45B。
- 字体沿用 Segoe UI / Microsoft YaHei UI；标题 11px，金额 26px，状态约 9px，数字等宽。币种比数字小，避免挤占金额。
- 260×108 逻辑尺寸保持不变；左侧角色展示扩大到约 110px，头饰、耳朵和手爪保留；右侧信息左对齐。右上操作按钮始终可见。
- 状态以绿色工作点、金色午休点、淡紫下班小胶囊区分；隐私保留工作状态，并以小锁和遮盖金额明确提示。避免照搬设计图的大幅装饰。

```
┌ 角色头饰 / 猫耳       [眼睛][展开][设置][托盘] ┐
│                      今天已经赚到          │
│  清晰五官与手爪       ¥ 168.35 / ¥ ••••••    │
└                      ● 工作状态 [锁 隐藏]   ┘
```

方案复核：记忆点来自两套既有角色，配色来自参考图；不将整张参考图作为背景，不新增数字示例或第二套状态逻辑。少量气泡/猫爪装饰仅作为主题识别，隐私时角色继续按真实工作状态变化。

## 完成与验收（2026-10-13）

展示调整：蓝主题采用深蓝金额与冰蓝描边，咪宝保留奶油底色与棕色数字。角色源图宽度从 154/164px 提高到 200px，通过 110px 展示区域和各姿态偏移保留脸部、头饰/猫耳、双手/前爪；只裁去两侧长发和身体边缘。卡片提高到 95px，位置 y=8；右侧标题、金额与状态依次排列，减少原有角色周围空白。币种缩小，金额按格式化后的字符长度适配，验证范围含 10 亿日收入上限。

午休使用金色状态点与充电文案，下班使用淡紫简短胶囊。隐私金额继续直接渲染六个圆点，加入锁形提示；角色与工作状态保留。按钮顺序为眼睛、展开、设置、托盘；始终可见，键盘顺序相同，隐藏状态按钮有主题色底。完整模式仅补充锁图标与隐私按钮选中状态。

素材来源：复用项目两套主题原有的上班、午休、下班透明 PNG，以及咪宝现有猫爪 SVG；气泡由小面积 CSS 描边构成。没有新增或覆盖人物素材，没有用整张参考图充当 UI。

原生尺寸保持完整 260×276、迷你 260×108、设置 400×600。本轮没有修改 Rust、工资公式、配置保存或窗口位置逻辑，没有新增依赖。
