# 设置界面方案 A

以现有 400×600 设置窗口为约束，保留六个字段、工时提示、实时日薪时薪和保存按钮。视觉重心为同一名蓝发女孩「拿计算器、托腮思考」，使用独立透明图片，不复用主组件的截断探头图。

配色：冰白 #F7FBFF、浅蓝边框 #CFE6FB、计算器蓝 #4A9DFF、按钮蓝 #2E7FE0、标题深蓝 #20354A、辅助蓝灰 #6F8BA1。沿用 Segoe UI / Microsoft YaHei UI，标题 20px、输入 14px、说明 12px。

```text
╭────────────────────────── × ╮
│      拿计算器、托腮的女孩     │ 190×140 独立图片框
│    先来算算你的打工身价！    │ 居中标题
│     保存后按新设置重新计算    │ 一行辅助说明
│ 月薪            工作天数    │
│ 上班            下班        │ 原有双列真实表单
│ 午休开始        午休结束    │
│       每日有效工作时长       │
│ 打工身价       日薪 / 时薪  │ 实时计算
│          保存设置           │
╰────────────────────────────╯
```

审查取舍：参考图中的纸张、星星和猫爪不加入页面，保持人物与表单清晰。取消原探头图的底部遮罩及 64px 无效间距，用完整图片的实际高度组织标题。所有 CSS 修改只作用于设置区域，主组件样式和人物资源不修改。人物不强行模拟眨眼，只保留 3.8 秒、不到 1px 的轻微整体呼吸；减少动态效果时关闭。
