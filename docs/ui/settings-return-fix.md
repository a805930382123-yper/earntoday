# 设置返回与图二布局修复

问题定位：用户图一对应上一轮引入的大人物（232px）、矮卡片（234×123px）及等大小数样式。设置返回路径仍调用原生 260×240 尺寸恢复，主要视觉偏差来自上一轮样式比例改动。

本次以用户图二为基准恢复小人物、较高的浅蓝圆角卡片、较大的标题、较小的小数、细进度条和更清晰的底部工时排版。午休睡眠素材与时间计算规则保留。金额容器固定宽度并居中，移除更新时的区域宽度变化。

修改文件：`src/widget.css`、`src/components/ChibiGirl.tsx`；回归脚本为 `tools/verify-widget.cjs` 和 `tools/verify-desktop.cjs`。没有修改真实工资配置或系统时间。

浏览器回归现已模拟与原生一致的尺寸切换：设置 400×600，返回 260×240。连续五次进入/返回、重新加载后再进入/返回，以及午休边界、冷启动、修改午休时段、减少动态效果和监听释放均通过。31 项计算测试和 TypeScript 检查通过。

截图使用禁用瞬间动画的截图选项，避免模拟时钟暂停导致把角色交叉淡入淡出或进度动画截在中间。该选项只影响测试截图，不改变产品动画。
