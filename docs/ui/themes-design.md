# 皮肤主题 V1 设计

基础：现有单 WebView、共享工资/时间算法、固定260×276主窗和400×600设置窗。默认角色使用原四张PNG，不复制不重新生成。主题在App上层统一管理，Rust独立selectedThemeId持久化；子页导航保留Settings组件与表单草稿。

色板：蓝色大肥鱼沿用冰白#f7fbff、柔蓝#b9d9ff、主蓝#4a9dff、金额蓝#2277e2、文字#20354a；开发测试主题采用紫#9673e0与暖粉#f3dcf0，保留同一结构。
字体：沿用Segoe UI Variable Display和微软雅黑，标题20px，名称14px，正文12px。保持成熟主组件和设置表单几何。

```

                原190×140角色
              原标题与六字段表单

       选一个喜欢的小伙伴，陪你度过打工时光。

       [上班图] [午休图] [下班图]

```

审查：只有一套正式皮肤，不制造假商店和锁定卡片。封面与缩略图都来自现有真实资产；一处卡片足够，预览是主视觉。入口放在设置原顶部留白，不插入表单行，避免保存按钮被挤出窗口。测试主题不进入公开列表。交互关注预览和应用的分离、保存失败提示、资源加载失败回退，避免金额和状态重新挂载。
